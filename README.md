# 🚇 4호선 LCD 프로젝트 (웹 버전)

서울 지하철 4호선 열차 LCD/안내방송 시뮬레이터. 설치 없이 브라우저에서 바로 실행됩니다.

## GitHub Pages로 배포하기
1. 이 폴더의 파일을 전부 저장소 루트에 올립니다 (`index.html`이 루트에 있어야 합니다).
2. 저장소 **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** → Save
3. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 실행됩니다.

## 로컬에서 실행
`index.html`을 더블클릭하면 ES 모듈 제한 때문에 동작하지 않습니다. 간이 서버를 쓰세요.
```
python -m http.server 8000   # 후 http://localhost:8000
```

## 사용 방법
- **표시화면 새 창**: 별도 창(다른 모니터)에 승객용 화면을 띄웁니다. 창에서 `F`로 전체화면.
- 행선지 글씨 위치는 방향키로 조절합니다.
- **출발화면/방송**: 1번 출발화면 → 2번 방송 → 3번 원래대로. 출발화면 중에는 다른 버튼이 잠깁니다.
- **대기**: 노선도 화면 토글. 대기 화면에서 역 전환은 피하세요.
- 행선지는 진접행/사당행만 지원합니다.

## 참고
- 데스크톱(Python/Tkinter) 버전을 웹으로 포팅했습니다. 이미지 순환(5초)은 그대로이며, 버튼 조작은 바로 반영됩니다.
- 파일 경로는 GitHub Pages의 대소문자 구분 때문에 영문 소문자로 정리했습니다 (`assets/img/<역>/<방향>/N.png`).
